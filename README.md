# 早日发Paper

一个本地保存文档、使用 MinerU 解析 PDF 并通过大模型或 Edge 翻译的桌面阅读器。独立开发，不使用靠岸学术的代码、素材或私有接口。MIT 开源。

当前源码接入 MinerU，以及云端 API、本地大模型和免费 Edge 翻译。在“翻译配置”栏目内切换，云端和本地服务的地址、模型名称 和密钥分别保存。Edge 无需密钥，使用 `https://edge.microsoft.com/translate/translatetext`，请求正文为文本字符串数组。项目关系、清理记录和完整测试范围见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 运行

普通用户可使用仓库 Releases 中的 Windows 便携压缩包：完整解压后运行 `早日发Paper.exe`。源码仓库不包含安装包、依赖、本地模型或个人配置；没有发行版时，启动脚本按源码方式启动。

Windows 用户双击 `启动早日发Paper.cmd`（旧的 `启动文桥.cmd` 也可使用）。如果已生成桌面发行版，启动器优先打开最新精简版；也可以直接运行 `release/0.1.5/早日发Paper-win32-x64/早日发Paper.exe`。发行版文件夹需要完整保留，不能单独复制 EXE。

从源码运行需要 Node.js 24 或兼容的新版本：

```powershell
npm.cmd ci
npm.cmd start
```

构建 Windows x64 便携文件夹和分享 ZIP：

```powershell
npm.cmd run package
```

产物为 `release/0.1.5/早日发Paper-win32-x64/` 和 `release/早日发Paper-0.1.5-Windows-x64-slim.zip`。打包只取必要运行文件，将主进程和界面依赖合并压缩，公式库仅保留界面所需的样式和字体，保留第三方许可与中英文运行时语言包。不会打入用户配置、个人文档、本地模型、开发依赖或测试文件。

无需配置数据库。应用使用 Electron，界面为普通 HTML/CSS/JavaScript。首次安装依赖需要网络；打包复用已安装的 Electron，不再额外下载运行时。打包产物尚未做代码签名。

## 使用流程

1. 默认使用免费的 Edge 翻译，无需密钥。点击文档侧栏顶部蓝色“API 与偏好设置”按钮配置服务；文档解析栏目顶部提供“文档解析api申请网址”，点击在默认浏览器打开 MinerU 申请页面；“文档解析”和“翻译配置”默认折叠，点击标题展开，输入区域用缩进和颜色区分。每次修改自动保存，API Key 加密保存在本机并保持隐藏。保存失败也可点击关闭或按 Esc 退出；未保存输入保留在内存中，重新打开设置可以继续修改，退出软件后则使用上次成功保存的配置。打开设置会暂停边读边译，关闭后恢复先前的阅读任务；更换翻译配置或测试连接成功后，关闭设置会继续未完成的翻译。同语言切换云端服务或模型不会删除已保存的译文。云端 API 与本地模型仍可切换使用，原配置保留。
2. 文档解析配置填写 MinerU Token。翻译配置填写兼容 OpenAI Chat Completions 的服务地址、API Key、模型名称、语言和可选术语偏好。云端服务可能产生调用费用。
   使用本地模型时，在同一栏目选择“本地大模型”，填写本机服务地址、模型名称 和可选 API Key。先启动本机服务并加载模型，再点击“测试翻译连接”。例如 [Ollama](https://docs.ollama.com/api/openai-compatibility) 地址可填 `http://127.0.0.1:11434/v1`；[LM Studio](https://lmstudio.ai/docs/developer/openai-compat/chat-completions) 可填 `http://127.0.0.1:1234/v1`。模型名称 填本机服务中实际使用的名称。这里连接已运行的模型服务，不直接加载权重文件。
   使用 Edge 时，选择“Edge 翻译（免费）”，默认 English → 简体中文即可。可填写语言代码，如 en、zh-Hans、ja；原文可填 auto 自动识别。无需填写 API Key、地址或模型名称，术语偏好不适用于此方式。切换方式会保留原来的云端、本地配置及相同语言的缓存译文。
3. 导入 PDF 后应用会自动提交解析，并在主界面显示解析进度或错误；如已下载解析结果但上次处理失败，会先从本机 ZIP 恢复。也可导入 UTF-8 Markdown 跳过 MinerU。Markdown 图片仅复制同目录或子目录中的常见位图，外部图片不会自动下载。
4. 边读边译默认开启，可在顶栏切换并记住选择；关闭会停止自动翻译，仍可手动翻译全文。开启时，文档打开后自动将可视阅读块加入边读边译队列，并用后续未翻译内容补满当前请求；翻译期间滚动后，新看到的内容优先排队。长段落按合适边界拆成约 360 字符的小块，并保留强调、链接、行内公式和代码。云端翻译和连接测试共享用户设置的请求间隔，请求间隔可在云端配置中设置为 0–120 秒，按两次请求开始时间计算；设为 0 时不额外限频；本地和 Edge 请求串行运行，不加频率间隔。云端默认每次最多 20 个文本片段、4000 个字符，配置中可分别调整为 1–200 个片段和 500–22500 个字符，达到任一上限就分批；发送量和间隔设置用于全文翻译、单块或全文重译、边读边译，连接测试共享间隔。Edge 单次最多合并 200 个文本片段或 22500 个字符，本地单次最多 80 个片段、默认 3000 字符，可在设置里调高字数上限。译文按原文块 ID 校验并自动保存，暂停会中止在途请求并保留已保存译文和队列。全部完成后自动释放任务。点击“翻译全文”处理所有剩余内容。支持单块编辑、重译、复制和阅读位置恢复。顶栏“清空译文”在确认后停止当前文档的翻译，清空机器译文、人工编辑、历史重译备份及缓存，关闭边读边译，保留原文和图片；其他文档不受影响。PDF 原件通过系统阅读器打开。
5. “导出”会生成包含 Markdown 和本地图片的 ZIP，支持原文、译文、双语。未完成段落保留原文并标明。

内置示例默认使用 Edge 边读边译，文本会发送给 Microsoft Edge 服务；已有译文可离线阅读。示例数字只是演示，不代表实际研究结果。

## 阅读与文档管理

- 阅读顶栏右侧“文内搜索”或 Ctrl＋F 打开当前文档的搜索面板，检索原文及已保存、可显示的译文，忽略大小写，按字面文字匹配。所有匹配逐项列出，包括同一段中的多次出现，并显示原文/译文标记和上下文。点击结果定位并高亮具体文字；长表格会自动横向和纵向滚动，隐藏的对应语言会临时显示，可用“返回原位置”恢复。Esc 关闭搜索，切换或删除文档清空结果。窄窗口选择结果后自动收起面板，避免遮住正文。侧栏“搜索文档名称”仍只筛选文件名称。检索本身不发送翻译请求，不搜索图片内文字。
- 顶部“白天／黑夜”按钮显示当前主题，点击切换完整界面主题，侧栏、正文、表格、设置窗口及系统标题栏一起更新，选择保存在本机。切换主题不会暂停翻译或重建正文。API 设置位于文档侧栏顶部，导入按钮位于文档列表下方；阅读模式、翻译、重译、导出和沉浸集中在顶栏，文内搜索位于阅读按钮右侧。底部不再显示本地保存说明和排队数量。可切换“左右对照”“上下对照”“原文”“译文”；左右对照按块对齐并同步滚动，保留原文节点与阅读位置。首次阅读默认左右对照，后续记住选择。
- 图片单独显示在共享区域，四种阅读模式都只展示一份；译文区域只显示翻译后的图标题、说明和正文。图片内容不做 OCR 翻译；原始图片和链接保留。
- 点击正文中的 Figure／Fig.、Table、Eq.／Equation 或“图／表／公式”编号，可跳转并短暂高亮对应对象，目标上方显示醒目的蓝色“返回原位置”悬浮按钮，可逐次返回。按钮随滚动、窗口大小和内容变化更新位置，保持在阅读区域内。四种阅读模式及沉浸阅读均可使用；翻译加载改变页面高度后，仍按原阅读块和屏幕偏移返回。编号重复或缺失时先选择目标，选择按文档保存在本机；Shift 点击引用可重新选择。定位使用原文标题、相邻图表说明及公式编号，不调用翻译 API；这里定位的是解析后的阅读内容，不是 PDF 页码。
- 重译不再弹出确认框：单块重译成功后替换旧译文；全文重译直接开始，覆盖机器译文与人工修改前仍备份最近一次结果。短尾部会调整前后分块，避免把末尾单词独立成段。旧分块中同一段落的短尾部自动合并，保留已有译文；人工编辑过的碎块保持原样。
- 标题栏的侧栏图标可折叠文档列表，目录标题旁的侧栏图标可折叠目录；按钮无边框，目录收起后保留入口。拖动两栏之间的分隔条可调整宽度；按住 Ctrl 并滚动鼠标滚轮可调整正文字号。沉浸阅读会扩展正文，状态信息收在右下角，按 Esc 可退出。阅读偏好保存在本机。
- 每个成功收到的翻译片段立即写入本机。重新打开、滚动回看、继续队列或再次导入同一文件都会复用已有译文；只有主动选择“重译”才重新请求已译内容。
- 点击段落方框后可复制 Markdown。复制通过桌面剪贴板接口完成，不依赖浏览器剪贴板写入权限，并保留空格、换行和公式源码。
- 右键点击侧栏文档，可打开文件所在文件夹、重命名或永久删除。文档行不显示独立删除按钮。重命名只修改显示名称，编号文件夹、原件和缓存保持原位。永久删除确认窗口默认取消，确认后不会进入回收站。删除文桥内的副本、译文、图片、解析结果和队列，导入时的原文件及已导出文件不受影响。翻译或解析正在运行时，重命名和删除不可用，请先暂停。


## 这个最小版本的边界

- 一次只运行一个文档任务，翻译请求串行。使用按文件原子替换的 JSON 存储，没有 SQLite、登录、云同步或向量数据库。
- MinerU 使用官方精准解析流程：申请上传链接 → PUT PDF → 查询批次 → 下载 ZIP。服务限制以官方为准；本版额外限制 PDF 200 MB、Markdown 5 MB、ZIP 下载 250 MB、解压元数据总量 500 MB。
- 翻译从 Markdown 语法树提取文字片段，保留公式、代码、图片、链接地址及排版节点。强调、链接文字与表格单元格作为可追踪片段翻译，大模型得到同批片段作为上下文。复杂长句跨格式片段时可能影响流畅度。
- Markdown 与 HTML 表格均按文字片段翻译，包含表头、表注及单元格；HTML 标签、合并单元格、公式、代码和图片保留。已导入的 HTML 表格重新打开后自动升级为可翻译，无需重传 PDF。表格不拆成普通段落。公式在原文、译文中使用本机 KaTeX 渲染，支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`；参考文献与图片内部文字仍默认保留。SVG 等非位图资源暂不加载。没有 PDF 区域定位、页码映射、图内翻译或原版式 PDF 导出。原始 LaTeX 不合法时保留可核对的错误内容，不猜测修改公式。
- 长普通段落按合适边界切为约 360 字符的阅读块；行内公式与代码完整保留，表格、参考文献以及无法安全切分的结构保持原样。模型批次使用字符预算而非精确 token 计量；云端与 Edge 单次限时 120 秒，本地单次限时 180 秒，连接测试限时 20 秒。超时会中止 HTTP 请求并暂停任务，不关闭用户自行启动的模型服务。模型超限、输出截断或格式无效时停下并给出原因，由用户重试，不隐性自动重发付费请求。
- 校验返回 ID、完整性与非空内容，不进行数字差异检测或添加数字核对提示。校验不等于语义准确；术语、数据和结论仍需人工核对。
- 暂停会中止排队和在途请求，等待本机保存结束后释放任务。中断后手动继续，已落盘内容不重复翻译。在途请求如果没有收到返回，重新发送可能再次计费。打开设置会先暂停当前任务，设置修改自动保存，关闭前完成待保存内容。暂停的 PDF 可点击“继续解析”复用原批次。
- 用量仅累计成功收到并校验的响应中所报告的 usage，不是完整账单。未收到或校验未通过的响应仍可能产生费用。本版没有金额预算或计费硬上限。
- 翻译配置或语言改变时，恢复任务会提示配置不一致；可选择“重新翻译全文”。该操作会替换译文与人工修改，但先保存最近一次 `previous-translation.json` 供手工恢复。
- 单段重译采用暂存，只有新结果完整成功后才替换旧译文。跨请求中断时保留旧结果。
- 未实现批量导入、拖拽、文献搜索服务、Word 导出、自动更新、跨平台发行或完整 PRD 中的所有 P0 功能。这是核心流程最小版。

## 密钥与本地数据

设置页面可打开数据目录，Windows 默认位于当前用户 `%APPDATA%/paperbridge`（实际路径由 Electron 决定）。密钥使用 Electron safeStorage 加密保存，设置页默认隐藏已保存密钥，可按“显示”临时查看后再隐藏；修改后自动保存。系统安全存储不可用时，应用不会保存密钥。

本地数据包含 PDF 副本、原始 MinerU 结果 ZIP、Markdown、图片、任务记录、机器译文与人工修改。上传尚未完成时，记录中还可能暂存有时效的签名上传 URL。云端与本地服务的密钥独立加密保存；切换服务不会将云端密钥发给本地模型。API Token 不写入文档记录，也不包含在导出包内。

每篇文档使用独立的 `documents/<文档ID>/` 子文件夹，ID 避免重名文件冲突。PDF 文档解析后包含：

```text
documents/<文档ID>/
  original.pdf            导入的 PDF 副本（仅 PDF 文档）
  original.md             导入或 MinerU 返回的原始 Markdown
  parsed.md               阅读用原文 Markdown
  translated.md           译文 Markdown，翻译和人工编辑后自动更新
  content/                本地图片，生成的 Markdown 通过相对路径引用
  document.json           任务状态、译文缓存和人工编辑记录
  mineru-result.zip       原始解析结果（PDF 文档）
```

尚未解析的 PDF 先保存原件，解析成功后生成 Markdown；直接导入 Markdown 不会生成 PDF。旧文档启动时从已保存记录补齐 `parsed.md`、`translated.md`，不重新调用翻译服务。未译完的部分在译文文件中保留原文并标注。生成文件由软件维护；修改译文请使用软件中的“编辑”，直接修改生成文件会在后续保存时被覆盖。

Windows 可能将部分 AppData 文档重定向到应用缓存，逻辑目录与实际目录不一致；右键“打开文件所在文件夹”会打开该文档的实际位置。读取和删除仅使用经过文档 ID、直接子目录和目录链接检查的路径，拒绝显式符号链接或目录联接。

解析会把 PDF 上传到 MinerU；云端翻译将文字与术语偏好发送给配置的服务，本地翻译只访问本机地址。导入 Markdown 后使用本地翻译可离线完成核心流程；已有结果可断网阅读。

不要把数据目录、真实论文或密钥提交到 Git。仓库的 `.gitignore` 已排除依赖和构建产物。

## 源文件

| 文件 | 用途 |
| --- | --- |
| `main.mjs` | Electron 桌面入口、本地存储、MinerU/翻译请求、任务与导出 |
| `document.mjs` | Markdown 语法树、内容块、译文回填和校验 |
| `files.mjs` | 支持 Windows 短暂文件占用的原子保存、受大小限制的 ZIP 读取 |
| `translation-queue.mjs` | 阅读段落队列、去重与优先级 |
| `translation.mjs` | 统一批量规则、请求估算、缓存复用与译文回填 |
| `translation-timeout.mjs` | 超时强停与立即取消 |
| `translation-rate-limit.mjs` | 云端入口共用的可配置请求间隔，0 表示不额外等待 |
| `references.mjs` | 中英文图表公式编号、对象索引及跳转候选 |
| `preload.cjs` | 限定的页面调用接口 |
| `index.html`、`style.css`、`renderer.js` | 阅读器与设置界面 |
| `sample.md` | 离线可打开的示例 |

`npm test` 检查 ZIP 解压、大小限制、文件占用重试、并发保存、分块、队列恢复、批次边界、缓存、超时与暂停；不调用外部 API。`npm run check` 做 JavaScript 语法检查，`npm run build` 构建界面资源。真实 API 调用需要已开通服务的密钥。

`npm run test:ui` 在独立临时用户目录中运行 Electron 界面回归，不读取真实文库或调用翻译服务。检查打开文档自动排队、折叠控件、Ctrl＋滚轮字号、沉浸框、原文/选区保留、整段显示、暂停时的译文，以及插入新译文时阅读位置偏移小于 1 像素。另检查引用导航、文档右键操作、文内搜索全部匹配、特殊字符、隐藏语言跳转、长表格滚动、更新及文档切换清理，以及浏览器剪贴板权限被拒绝时的桌面复制。

`npm run test:app` 使用真实主程序与页面接口，在独立临时文库中模拟 MinerU 和翻译服务。检查密钥加密、批量请求、缓存跳过、卡住请求的暂停、单块重译失败保护、PDF 暂停与恢复、图片 ZIP 导出、文档文件夹 Markdown 自动更新、旧文件补齐、右键菜单、重命名和永久删除。测试不会发送真实付费请求或删除用户文档。

本项目许可证见 `LICENSE`，第三方依赖按各自许可证使用；锁定版本记录在 `package-lock.json`。

首次启动默认白天主题；主动选择的主题会保留，顶栏可随时切换白天与黑夜。

软件显示名称为“早日发Paper”，为保留已有文档和 API 配置，用户数据目录仍沿用 `%APPDATA%/PaperBridge`。设置底部的“关于作者”可打开作者说明。窗口最小尺寸为 720×480；文档侧栏可缩至 140px、目录可缩至 120px，继续缩小时自动隐藏，重新打开恢复上一次可用宽度。目录按钮根据状态显示“打开目录／隐藏目录”，隐藏后目录不再占用横向空间。

界面测试截图生成到项目内的 `artifacts/`，该目录不会提交到 GitHub。
